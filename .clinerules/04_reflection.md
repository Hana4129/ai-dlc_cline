# 04_reflection.md — 振り返りフェーズのルール

## 目的

ループの知見を蓄積し、次のループの質を上げる。
記録は `loop-log.md` に追記する。

---

## 振り返りの手順

1. ループの結果を評価する（成功 / 部分成功 / 失敗）
2. うまくいったこと・いかなかったことを記録する
3. 次のループへの引き継ぎ事項を明確にする
4. `loop-log.md` に追記する

---

## loop-log.md の記録フォーマット

```markdown
## Loop #<N> — <YYYY-MM-DD>

### 目標
<計画フェーズで宣言した目標>

### 結果
- ステータス: 成功 / 部分成功 / 失敗
- 達成した完了基準:
  - [x] <基準1>
  - [ ] <基準2>（未達成の場合は理由も記述）

### 実施内容
- 変更ファイル: <ファイル一覧>
- 主な変更内容: <簡潔に>

### 学び・気づき
- <うまくいったこと>
- <うまくいかなかったこと・注意点>

### 次のループへの引き継ぎ
- <次にやること / 残課題>
```

---

## loop-log.md の管理ルール

- プロジェクトルートに配置する
- コミットに含める（チームで共有する）
- ファイルが存在しない場合は新規作成する
- 1ループ = 1エントリ、削除・上書きしない

---

## 振り返りフェーズの完了基準

- loop-log.md に今ループのエントリが追記されている
- 次のループの目標または「完了」が明確になっている
